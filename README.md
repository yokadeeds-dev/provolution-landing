# provolution-landing

Quellcode der wissenschaftlichen Landing-Page unter [provolution.org](https://provolution.org).

## Stack

- [Astro](https://astro.build/) (Static Site Generator)
- Deutsch primär; EN-Architektur vorbereitet (Astro `i18n`)
- Deployment via [Netlify](https://www.netlify.com/)

## Entwicklung

```bash
npm install
npm run dev      # Dev-Server unter http://localhost:4321
npm run build    # Statischer Build nach dist/
npm run preview  # Vorschau des Builds
```

## Inhalte

Texte werden aus dem CANON-Repository [yokadeeds-dev/Provolution](https://github.com/yokadeeds-dev/Provolution) abgeleitet (gekürzt, web-tauglich) &mdash; nie erfunden. Bei Versions-Updates der CANON-Kennzahlen ist die Website nachzuziehen.
